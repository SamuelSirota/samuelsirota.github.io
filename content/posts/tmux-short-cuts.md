Open tmux

```bash
tmux
```



Split pane vertically
```
C-b "
```

Split pane horizontally

```
C-b %
```

Change pane

```
C-b Up, C-b Down, C-b Left, C-b Right
```

Switch pane positions

```
C-b Shift-[
```

Close pane

```
C-b x
```

Create new window

```
C-b C
```

Change window

```
C-b N, C-b P, C-b <Window-ID>
```

Close window

```
C-b &
```


---

Show pane numbers

```
C-b Q
```
